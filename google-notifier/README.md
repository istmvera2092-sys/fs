# Почтовые уведомления Киновечера

Закрытый Google Apps Script проверяет очередь новых фильмов раз в минуту и отправляет письмо на `GovorunGoorushky@yandex.ru`. Очередь хранится в том же Google-проекте, где находятся фильмы. Публичный проект не содержит `MailApp`, чтобы его страница оставалась доступна приглашённым.

Исходный шаблон не содержит ключа очереди. Сборка подставляет `FILM_NOTIFY_KEY` из локального `.dev.vars` в `dist/Code.gs`; `dist/` исключён из Git. Ключ должен совпадать с ключом при сборке публичного Google-проекта.

```sh
node google-notifier/build.mjs
node google-notifier/test.mjs
cd google-notifier/dist
clasp push --force
```

Действующий закрытый проект: https://script.google.com/d/17ScaOTv4eBjsVF-SqewTC5Q1HM-Qjl4D7r80R9DKMrTTXBOthnjSCzfk/edit

При первом запуске откройте проект в редакторе Google Apps Script, выберите функцию `setupNotifier`, нажмите «Выполнить» и подтвердите разрешения. Она должна создать один ежеминутный триггер и отправить ожидающие письма. После запуска откройте слева раздел «Триггеры» и убедитесь, что строка `sendPendingNotifications` появилась. Если список пуст, нажмите «Добавить триггер» и выберите функцию `sendPendingNotifications`, источник «По времени», тип «Таймер по минутам», интервал «Каждую минуту». Повторный запуск `setupNotifier` не создаёт второй триггер. При ошибке отправки задание остаётся в очереди и повторится через пять минут.
