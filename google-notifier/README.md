# Почтовые уведомления Киновечера

Закрытый Google Apps Script проверяет очередь новых предложений раз в минуту и отправляет письмо на `GovorunGoorushky@yandex.ru`. Очередь хранится в том же Google-проекте, где находятся фильмы. Публичный проект не содержит `MailApp`, чтобы его страница оставалась доступна приглашённым.

Исходный шаблон не содержит ключа очереди. Сборка подставляет `FILM_NOTIFY_KEY` из локального `.dev.vars` в `dist/Code.gs`; `dist/` исключён из Git. Ключ должен совпадать с ключом при сборке публичного Google-проекта.

```sh
node google-notifier/build.mjs
node google-notifier/test.mjs
cd google-notifier/dist
clasp push --force
```

Действующий закрытый проект: https://script.google.com/d/17ScaOTv4eBjsVF-SqewTC5Q1HM-Qjl4D7r80R9DKMrTTXBOthnjSCzfk/edit

При первом запуске откройте проект в редакторе Google Apps Script, выберите функцию `setupNotifier`, нажмите «Выполнить» и подтвердите разрешения. Она создаёт один ежеминутный триггер и отправляет ожидающие письма. Повторный запуск не создаёт второй триггер. При ошибке отправки задание остаётся в очереди и повторится через пять минут.
