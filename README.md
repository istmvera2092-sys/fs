# Киновечер

Общий список фильмов с колесом случайного выбора, предложениями и отметками о просмотре. Участники входят по общему коду. Фильмы и статусы хранятся в Cloudflare D1.

Рабочий сайт: https://film-night-sophie-2026.sofy1991.chatgpt.site

## Что умеет сайт

- Добавлять фильм в предложения или сразу в список просмотра.
- Переносить предложения в список и выбирать фильм вращением колеса.
- Отмечать просмотренное и при необходимости возвращать фильм в список.
- Синхронизировать изменения между участниками через общую базу.
- Закрывать страницу и API фильмов серверной проверкой кода доступа.

## Локальный запуск

Нужны Node.js 22.13+ и зависимости из lockfile:

```sh
npm ci
```

Создайте локальный файл `.dev.vars` (он исключён из Git):

```text
FILM_ACCESS_CODE=ваш-код
FILM_SESSION_SECRET=случайная-строка-не-короче-32-байт
```

Соберите проект и примените миграцию к локальной D1:

```sh
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_puzzling_ultron.sql
npm run dev
```

Локальный адрес по умолчанию: http://127.0.0.1:5173.

## Размещение

Сайт сейчас размещён в OpenAI Sites как Cloudflare Worker с базой D1. Файл `.openai/hosting.json` связывает исходники с действующим Site. Переменные `FILM_ACCESS_CODE` и `FILM_SESSION_SECRET` задаются как секреты в настройках хостинга; их значения не хранятся в Git.

GitHub Pages подходит только для статических страниц и не запустит этот API и D1. Репозиторий `fs` служит копией исходников; действующий сайт работает по ссылке выше.
